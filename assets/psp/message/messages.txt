Implementation notes
- Messages 2–6, 13 and 19 use dynamically mapped game controls; use the existing PSP button graphic mapping.
- Speed Booster artwork: use the existing selected Speed Booster HUD icon.
- The supplied item icons have intentional opaque backgrounds; do not key them out or derive alpha from colour.
- The font atlas background is transparent. Use the BMFont .fnt metrics for glyph source rectangles, offsets, and advances.
- Messages 23 and 28 must display the current game-owned YES/NO selection. Do not change the original interaction or timing code.
- The native overlay dims gameplay only; HUD remains undimmed. This is a renderer presentation rule, not a game-logic change.
